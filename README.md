# ProyectFrontend
Este es un proyecto pensado para la carrera de Tec. Universitaria en Programación, para la materia de Frontend, en donde teníamos que aplicar los conocimientos de HTML, CSS y JS
Las consignas del trabajo consistian en los siguientes puntos:

● El sitio web debe contener al menos cinco (5) páginas HTML diferentes.

● Cada página debe incluir al menos cuatro (4) secciones.

● Una de las páginas debe utilizarse para mostrar un listado que se consumirá
desde un servicio externo (API Pública). El listado debe contener al menos 7
entidades (objetos).

● Una de las páginas debe contener un formulario de contacto con al menos 6
campos. Estos, no pueden ser todos de tipo texto. El formulario debe
validarse utilizando JavaScript, controlando:
    ○ Campos obligatorios.
    ○ Formatos correctos según el contexto de cada campo (por ejemplo,
email, número de teléfono, etc.).
    ○ Mostrar mensajes de error amigables en caso de validaciones fallidas.

● La página web en su totalidad debe de ser Responsive: Se debe ver bien
tanto en dispositivos móviles como de escritorio.

● Menú de navegación desplegable (hamburger menu) únicamente en versión
móvil.

● Footer de la página web debe contener links de al menos 2 redes sociales
con su respectivo logo (ejemplo: Instagram, facebook). Al hacer click se debe
abrir en una nueva pestaña la red social del cliente.

● Utilizar una hoja de estilos común para todo el sitio web en un archivo aparte
para los estilos CSS propios. No utilizar el atributo style directamente en los
tags HTML ni tampoco el elemento <style>.

● El proyecto web no puede ser 1 solo archivo .html utilizado como una “landing
page”. Cada página tiene su correspondiente archivo HTML


Explicaciones: 
- Las paginas son las siguientes:
    1) Battios.html
    2)Contacto.html
    3)Galeria.html
    4)Home.html
    5)Reseñas.html

Para que la pagina funcion correctamente, hacerla correr en Live Server.

Se tomo el enfoque de usar footer y header como dos html, que lo que hago es invocarlos en cada pagina, esto lo hago para no necesitar
estar constantemente escribiendo el mismo codigo.
